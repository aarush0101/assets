Simple Image Retriever

Fast, lightweight, and reliable image retrieval directly from GitHub Pages.

About This Project

Simple Image Retriever is a minimal GitHub Pages site built for fetching and serving stored images at edge. Whether you need quick access to assets or lightweight hosting, this solution delivers.

How It Works

To access an image, simply visit:

/imgs/{image_name}

Replace {image_name} with the actual file name of the image stored in the repository.
